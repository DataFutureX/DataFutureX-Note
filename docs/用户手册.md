# DataFutureX-Note 用户手册

## 1. 安装与启动

1. 运行 `DataFutureX-Note-*-Setup.exe` 一键安装（请先拷到本地磁盘，不要从压缩包内直接运行）。
2. 安装向导第一步选择安装路径（默认 `%LOCALAPPDATA%\Programs\DataFutureX-Note`），也可点「浏览」自选。**覆盖安装**时会自动定位原目录。若选 `C:\Program Files` 等系统目录提示无法写入，可按提示以管理员身份安装，或改选用户目录（如 `D:\Apps`）。
3. 确认安装后进入进度页；完成后可点「启动」立即打开，桌面也会生成「DataFutureX Note」快捷方式；也可在开始菜单搜索「数字未来笔记」或「DataFutureX Note」。
4. 启动后首次使用需选择本地笔记库根目录；选择已有或空目录均可，软件不会清空该目录。

### 用本程序打开其他 Markdown

安装后可将 `.md` / `.markdown` 关联到本程序（或在资源管理器中「打开方式」选择 DataFutureX Note）：

- **已设置笔记库后**：正常启动始终进入该笔记库；不会因打开其他路径的 MD 而改掉库根
- **文件已在当前笔记库内**：在主窗口直接打开该笔记
- **文件在笔记库外**：额外启动一个独立进程查看（默认隐藏目录栏），主窗口笔记库保持不变
- 查看窗口需要时可点标题栏目录按钮再展开目录

## 2. 主界面

从左到右：

1. **目录**：文件夹树
2. **章节**：当前文件夹下的 Markdown 笔记
3. **内容**：编辑器 / 预览

可拖动分隔条调整栏宽，也可折叠目录或章节栏。

## 3. 笔记管理

- **新建笔记 / 新建文件夹**：顶部工具栏
- **拖动移动**：在左侧目录中拖动笔记或文件夹，放到目标文件夹上
- **重命名 / 删除**：在目录或笔记项上右键
- **复制笔记**：右键输入 `COPY`
- **保存**：Ctrl+S；默认开启约 1 秒自动保存
- **排序**：修改时间或名称升/降序

## 3.1 类 Typora 编辑

默认使用 **即时** 模式：在渲染预览上直接编辑，光标所在行显示 Markdown 标记，离开后自动还原为预览样式。

视图切换：

- **即时**：所见即所得（推荐，类似 Typora）
- **源码**：纯 Markdown 源码（CodeMirror）
- **分屏**：源码 + 预览
- **预览**：只读预览

常用快捷键（即时 / 源码）：

| 快捷键 | 作用 |
|---|---|
| Ctrl+B | 加粗 |
| Ctrl+I | 斜体 |
| Ctrl+D | 删除线 |
| Ctrl+K | 链接 |
| Ctrl+Shift+K | 代码块 |
| Ctrl+E | 行内代码（源码模式） |
| Ctrl+1 / 2 / 3 | 一/二/三级标题（源码模式） |
| Ctrl+S | 保存 |
| Tab / Shift+Tab | 缩进 / 取消缩进 |

工具栏也可插入标题、列表、表格、图片等。粘贴或上传的图片会保存到当前笔记目录的 `assets/` 下。

截图贴入：`Win+Shift+S` 截图后，在笔记编辑区按 `Ctrl+V` 即可贴入（也会保存到该笔记的 `assets/`）。工具栏「粘贴截图」为同一能力。

## 4. 搜索

顶部搜索框可搜索笔记标题和正文，点击结果即可打开。

## 5. 备份与导入

- **整库备份**：打包整个笔记库为 ZIP
- **备份当前夹**：仅备份当前选中文件夹
- **导入**：选择 ZIP，导入到当前文件夹；默认跳过同名冲突

## 6. 导出

打开笔记后点击「导出」：

- Markdown
- Word (DOCX)
- PDF

导出不会修改原始 `.md` 文件。

## 7. 主题

可切换明暗模式：

- 浅色
- 深色
- 跟随系统（默认）

还可切换主题色；切换浅色/深色时，会使用**当前主题色对应的浅/深变体**：

- **暖黄**：便签随手记
- **柔蓝**：知识管理（默认）
- **纸感**：长时间写作
- **柔绿**：学习专注
- **灰白**：浅灰极简（浅色灰白底 / 深色深灰底）

入口：设置页，或菜单 View → 主题色。

## 8. 设置

可切换笔记库根目录、自动保存、默认排序、启动行为、明暗主题与主题色。切换根目录不会删除原数据。
