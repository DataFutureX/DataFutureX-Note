# DataFutureX-Note 架构说明

## 技术栈

- Electron 桌面容器
- Vue 3 + TypeScript + Vite
- Pinia 状态管理
- Element Plus 基础控件
- CodeMirror 6 Markdown 编辑
- markdown-it + DOMPurify 预览
- adm-zip 备份导入
- docx Word 导出
- Electron `printToPDF` PDF 导出

## 进程模型

```text
Renderer (Vue)
    ↓ preload 白名单 API
Main (Electron)
    ↓ Node.js fs
本地笔记库根目录 / userData
```

- 渲染进程不直接访问文件系统。
- 主进程通过服务层完成 CRUD、搜索、备份、导入、导出。
- `folderId` / `noteId` 为根目录内相对路径，所有操作做边界校验。

## 数据事实来源

- 笔记正文：用户指定目录下的 `.md` 文件。
- 配置、恢复草稿、日志：Electron `userData`，与笔记正文分离。

## 安全

- `contextIsolation: true`，`nodeIntegration: false`
- ZIP Zip Slip 防护、文件数/体积/压缩比限制
- Markdown HTML 过滤，外链系统浏览器打开
- 原子写文件，外部修改冲突提示
