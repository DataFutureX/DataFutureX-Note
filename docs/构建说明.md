# 构建说明

## 环境

- Node.js 20+
- Windows 10/11 x64

## 安装依赖

```bash
npm install
```

若 Electron 二进制下载失败，可设置镜像：

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install
```

或从缓存解压到 `node_modules/electron/dist`。

## 开发运行

```bash
npm run dev
```

## 测试

```bash
npm test
node scripts/smoke-fs.mjs
```

## 生产构建

```powershell
$env:TEMP="D:\CodeWorkspace\codex\DataFutureX-Note\.tmp"
$env:TMP=$env:TEMP
$env:ELECTRON_BUILDER_CACHE="D:\CodeWorkspace\codex\DataFutureX-Note\.electron-builder-cache"
npm run typecheck
npm run build:vite
npx electron-builder --win --x64
```

产物：

- 免安装目录：`release/win-unpacked/DataFutureX Note.exe`
- 安装包：`release/DataFutureX Note-1.0.0-Setup.exe`

安装完成后：

- 桌面快捷方式：**数字未来笔记**（图标为 Logo `resources/icon.ico`）
- 开始菜单可搜：**数字未来笔记**、**DataFutureX Note**；亦可在「DataFutureX」文件夹中找到

快捷方式由 `build/installer.nsh` 创建，图标指向安装目录中的 Logo（`icon.ico`，由 `logo-mark` / `npm run icon` 生成）。

打包时 `scripts/after-pack.mjs` 会用 `scripts/bin/rcedit-x64.exe` 把 Logo 写入 `DataFutureX Note.exe`，桌面快捷方式即使跟随 exe 图标也会显示 Logo。

重新打包前建议：

```bash
npm run icon
npm run build
```

说明：`signAndEditExecutable` 仍为 false（避开 winCodeSign 缓存问题），图标改由 afterPack 写入。发布签名可在具备证书的环境另行开启。
