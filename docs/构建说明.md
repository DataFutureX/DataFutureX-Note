# 构建说明

## 环境

- Node.js 20+
- Windows 10/11 x64

## 安装依赖

```bash
npm install
```

若 Electron 二进制下载失败，可设置镜像：

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install
```

或从缓存解压到 `node_modules/electron/dist`。

## 开发运行

```bash
npm run dev
```

## 测试

```bash
npm test
node scripts/smoke-fs.mjs
```

## 生产构建

```bash
npm run build
```

产物：

- 免安装目录：`release/win-unpacked/DataFutureX Note.exe`
- 安装包：`release/DataFutureX-Note-*-Setup.exe`（单文件）

安装位置：默认 `%LOCALAPPDATA%\Programs\DataFutureX-Note`（可在安装向导中修改）

说明：安装包由 `scripts/wrap-installer.mjs` 将 `win-unpacked` 打成 zip 并嵌入自研安装器，**不再使用 NSIS**，以避免本机 Temp/写入文件夹失败。

安装向导（三步）：

1. **路径选择**：顶部显示 Logo 与「DataFutureX 数字未来笔记」；若已安装过，自动填入原安装目录便于覆盖安装
2. **安装进度**：显示写入进度百分比
3. **完成**：提供「启动」按钮立即打开应用

重新打包前建议：

```bash
npm run icon
npm run build
```

`signAndEditExecutable` 为 false（避开 winCodeSign 缓存问题），图标由 `afterPack` 写入。发布签名可在具备证书的环境另行开启。
