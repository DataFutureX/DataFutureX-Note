# 构建说明

## 环境

- Node.js 20+
- Windows 10/11 x64

## 安装依赖

```bash
npm install
```

若 Electron 二进制下载失败，可设置镜像：

```powershell
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install
```

或从缓存解压到 `node_modules/electron/dist`。

## 开发运行

```bash
npm run dev
```

## 测试

```bash
npm test
node scripts/smoke-fs.mjs
```

## 生产构建

```powershell
$env:TEMP="D:\CodeWorkspace\codex\DataFutureX-Note\.tmp"
$env:TMP=$env:TEMP
$env:ELECTRON_BUILDER_CACHE="D:\CodeWorkspace\codex\DataFutureX-Note\.electron-builder-cache"
npm run typecheck
npm run build:vite
npx electron-builder --win --x64
```

产物：

- 免安装目录：`release/win-unpacked/DataFutureX-Note.exe`
- 安装包：`release/DataFutureX-Note-1.0.0-Setup.exe`

说明：当前 Windows 打包关闭了 `signAndEditExecutable`，避免本机 winCodeSign 缓存权限问题；发布签名可在具备证书的环境另行开启。
